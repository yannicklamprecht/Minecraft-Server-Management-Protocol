# Gradle Plugin Integration Guide

`com.github.yannicklamprecht.mc.management.schema-extractor` is a Gradle plugin that:

1. Fetches the Mojang version manifest and downloads server JARs for the Minecraft versions you
   configure.
2. Runs each server's data generator to extract its Minecraft Server Management Protocol (MSMP)
   OpenRPC schema (deduplicated by protocol version - several Minecraft versions often speak the
   same MSMP protocol version).
3. Generates typed Java source (records, enums, API facades) from those schemas into your project.

Use this plugin when you want to **generate your own typed MSMP client** - for example, targeting
a different Java package, a different minimum Minecraft version, or simply to regenerate the
client this project already ships once new Minecraft/protocol versions are released. If you just
want to *use* an already-generated client in a Spring Boot application, you don't need this plugin
at all - go straight to the [Spring Boot starter guide](../spring-boot-starter/README.md).

## At a glance

```kotlin
// build.gradle.kts
plugins {
    id("com.github.yannicklamprecht.mc.management.schema-extractor")
}

minecraftManagement {
    packageName.set("com.example.myapp.msmp") // required
}
```

```bash
./gradlew build   # first run: extracts schemas, generates sources, then compiles them like any other code
                   # once sources exist, later runs just compile - see docs/gradle-plugin/tasks.md#auto-generation-on-build
```

This project's own `client/` module is generated by this exact plugin (see
`client/build.gradle.kts`), so it doubles as a complete worked example.
